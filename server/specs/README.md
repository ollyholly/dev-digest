# `@devdigest/api` — specs

Planning contracts for server work: goal, acceptance criteria, and blast
radius before implementation. Copy [`_TEMPLATE.md`](_TEMPLATE.md) into a new
file (e.g. `pulls-severity-rollup.md`) and fill it in.

**Not** browser e2e flows — those live in [`../../e2e/specs/`](../../e2e/specs/)
as `*.flow.json` for `agent-browser`.

**When to read / write:** before implementing a multi-file API or schema
change, or when handing work to an agent so scope and “done” are explicit.
