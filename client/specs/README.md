# `@devdigest/web` — specs

Planning contracts for client work: goal, acceptance criteria, and blast
radius before implementation. Copy [`_TEMPLATE.md`](_TEMPLATE.md) into a new
file (e.g. `findings-severity-filter.md`) and fill it in.

**Not** browser e2e flows — those live in [`../../e2e/specs/`](../../e2e/specs/)
as `*.flow.json` for `agent-browser`.

**When to read / write:** before implementing a multi-file UI feature, or when
handing a change to an agent so scope and “done” are explicit.
